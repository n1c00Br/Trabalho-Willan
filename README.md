Estrutura de Dados e Organização de Arquivos

Trabalho da disciplina de Estrutura de Dados e Organização de Arquivos feito em Python.

O que o sistema faz

O programa é um sistema de cadastro simples (nome, cidade e idade) rodando no terminal com as seguintes funções:

Incluir, Alterar e Excluir: manipula os registros dentro de uma lista de dicionários.

Salvar em JSON: toda vez que inclui, altera ou exclui um cadastro, os dados são gravados no arquivo dados.json e carregados automaticamente quando abre o programa de novo.

Pesquisa por texto: permite buscar registros digitando parte do nome ou da cidade.

Impressão ordenada: ordena e mostra a lista por 2 campos diferentes (nome em ordem alfabética ou idade em ordem crescente), usando laços de repetição para trocar os elementos de posição.
